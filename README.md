# AI 요리 시뮬레이터 웹 버전

## 실행

Python 3.10 이상에서 프로젝트 폴더의 PowerShell 터미널을 열고 실행합니다.

```powershell
python -m pip install -r requirements.txt
python web_app.py
```

브라우저에서 `http://127.0.0.1:5000`을 엽니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

## API 키

레시피 검색은 `SPOONACULAR_API_KEY`, 자동 번역은 `GOOGLE_TRANSLATE_API_KEY` 환경변수를 사용합니다. 키는 서버에서만 사용되며 브라우저에 전달되지 않습니다. 키가 없거나 외부 API를 쓸 수 없으면 기본 레시피로 실행됩니다. 번역 API 키가 설정되지 않은 경우 한국어 이외의 언어 선택 시 번역 설정 오류가 표시됩니다.

## 제공 기능

- 레시피 검색 및 냉장고 재료 기반 추천
- 브라우저에 재료·수량 저장
- 조리 타이머, 화력 조절, 단계 진행 및 결과 평가
- 재료를 냄비로 드래그하고 칼로 재료 자르기
- 한국어·영어·일본어·중국어 UI 자동 번역

웹 서버는 기본적으로 현재 컴퓨터에서만 접속할 수 있도록 `127.0.0.1`에 바인딩됩니다. 브라우저를 닫거나 앱을 재시작해도 냉장고 재료와 언어 선택은 해당 브라우저의 로컬 저장소에 남습니다.
